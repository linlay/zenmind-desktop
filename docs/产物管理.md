# 资料库

## 定位与所有权

资料库沿用原产物管理的 Desktop 原生能力页与入口身份，集中管理已发布文件的指针。Desktop SQLite 保存产物元信息、资料夹层级与归属、显示名称、收藏、标签和可用状态，不复制原文件；内容及生命周期仍由 Platform 和来源 Chat 拥有。删除来源对话会同时删除内容及这些资料的整理信息，用户创建的资料夹保留；归档期间资料暂不可读，恢复后重新同步。

第一版只管理正式发布的普通文件。图片、HTML、Office、代码、音视频、压缩包与未知格式均可收录；类型由 MIME 分类决定，不影响收录资格。项目 ZIP 作为普通文件处理，不提供目录发布、集合身份、项目运行、独立备份、版本历史或内容全文索引。未发布的图片、上传附件和 workspace 文件不会自动收录。HTML 的依赖资源仍受上游发布范围限制。

## 身份与存储

常规索引身份是 Chat、Run 与 Artifact 的组合，三者贯穿列表、整理和文件操作。同一 Artifact 在不同 Run 中独立展示；同一组合在权威 manifest 中出现多次时标记发布冲突，不静默选择其中一次。manifest、stream 和通知的时间可能存在差异，不能仅凭时间差判断重复发布。

旧数据库原位事务迁移，缺少 Run 的记录保留为待解析指针。仅在完整权威清单中找到身份和内容元信息唯一匹配时，将资料夹归属、显示名称、收藏和标签转移给已解析记录；多义匹配不任意分配。同步只能更新上游元信息，不能覆盖用户整理信息。文件路径、凭据和二进制不存入索引；路径仍由 Main 从受控来源即时解析。

来源状态、内容状态与访问状态分别保存。内容校验失败表示内容与发布记录不一致，不推断具体修改原因；网络错误和权限不足不能当成删除或归档。索引存在不授予文件访问权限，也不代表原件已经备份。

## 分层整理与浏览

资料夹是 Desktop 拥有的逻辑归类，由用户逐层创建；初始目录为空，不从对话、磁盘或示例内容推导。升级前的资料与新收录资料默认进入“待整理”。每条资料最多属于一个资料夹，收藏和标签可跨资料夹使用。移动只改变归属，重命名资料只改变显示名称；来源文件名、身份、路径与内容都不受影响。

资料夹导航的计数包含子孙资料，进入资料夹后显示直属资料及子资料夹入口，并通过面包屑返回上层。“全部资料”“最近生成”“我的收藏”和标签视图跨资料夹查询，“待整理”查询未归类资料。搜索及类型筛选作用于当前视图，排序以显示名称或原文件名为依据；它们不改变归类。

资料夹只允许删除空的叶节点，避免以整理操作隐式删除文件或批量改变归属。同层名称去重，层级有界。单条与批量移动、批量收藏都由 Main 验证身份和目标并事务写入；选择中有资料已被来源删除时整批失败，不出现部分移动。归类关系、别名和标签在重启及同步后保留。

页面采用资料夹导航、浏览区和可收起的详情区，窄窗口提供导航及详情覆盖层。小卡片、大卡片和列表是同一份查询结果的三种呈现，切换保留当前视图、选择与操作，呈现偏好在本地记忆。页首保持紧凑，不设置独立主题切换；弹出菜单沿用主导航的主题与交互样式。

## 增量、历史补齐与重连

Main 继续通过全局 Realtime Broker 的 internal consumer 订阅 Primary lane 产物通知，兼容已有 stream 窄回调和上传通知；资料库页面是否挂载不影响采集。不创建第二条连接、不 attach Run、不扫描服务目录。

经过协议校验的 Main 连接就绪后，以及用户主动重新同步时，Main 请求完整活跃对话列表，再按对话分页读取现有产物清单。当前对话列表没有历史分页游标，不能把 limit 或 lastRunId 伪装成历史分页；产物清单与归档列表按各自已有分页合同读取。并发有界，瞬时失败重试一次；权限不足保留索引并显示局部失败，用户可重新同步。产物发布不保证更新对话摘要时间，因此第一版不使用 updatedAt 水位排除待同步对话。

同步范围仅覆盖当前身份有权查询的活跃 Chat。Desktop 特定 sourceRef 读取权限不等于 list/get 或 Artifact 身份读取权限，不能相互替代。首次同步前已归档且从未收录的产物不能被现有接口发现，恢复来源后才可补齐。页面明确展示此范围、同步进度、失败和权限计数及最近同步时间，不把局部成功描述为完整历史。

## 对话生命周期与异步一致性

- 收到 chat.deleted 或 archive.deleted 后删除索引及资料的归属、显示名称、收藏、标签，保留用户创建的资料夹及内部删除标记，拒绝迟到推送重新创建记录。
- 收到 chat.archived 后标记来源归档并阻止打开；收到 archive.restored 后恢复来源并请求同步，保留整理信息。
- 重连结合完整活跃列表与归档列表对账：已知归档来源更新为归档；两份列表成功返回后仍未找到的来源标记暂不可用，不根据缺席直接清空资料。任一列表失败都不能视为空列表。
- 每次连接轮换和每个 Chat 生命周期变化使旧异步结果失效。删除、归档和恢复发生后，先前启动的清单读取不能回写旧状态；同步中收到发布通知会安排后续对账。断连及退出取消同步，迟到响应不更新本地数据库。

Desktop 原生对话删除弹窗提示当前资料库已收录数量及整理信息的删除影响。该数量只是本地索引数量，不承诺等于对话中的实际文件总数；未收录文件同样随对话删除。

## 文件动作与 UI 边界

Main 只给主窗口顶层 frame 暴露查询、重新同步、资料夹管理、资料整理及缩略图的受限 IPC。renderer 不直接访问 SQLite，不提交文件系统路径。写入后发布节流的无内容变更通知；列表使用视图、搜索、类型、收藏、标签与有界分页，迟到查询不能覆盖新结果。

图片卡片仅为受限大小的 PNG、JPEG、WebP 请求临时缩略图。Main 通过现有 artifacts/read 读取，约束响应大小，并比对本地记录的字节数、SHA 与文件签名；读取结束重新验证窗口、连接代次及来源生命周期。renderer 仅在内存中按需缓存有界数量，不落盘、不执行 HTML 或 SVG。其他格式沿用类型图标及既有打开流程。

查看、定位和外部打开仍从 Platform 对话的权威产物快照取得来源 Agent 与相对路径，以 Artifact 身份及路径中的 Run 精确匹配，拒绝多义结果和越界路径。不能从显示名称推算路径。查看复用来源 Chat 的 WorkPanel 文档 Surface，不修改 WebClient 合同。

下载按 Chat、Run 与 Artifact 调用现有 artifacts/read，由 Platform 校验文件大小与 SHA；失败保留具体错误。此保证只适用于该下载链路，不能宣称现有所有预览和本地打开均已获得相同校验。来源归档、身份待解析或发布冲突明确拒绝文件动作。动作跨越网络、文件选择器或应用查询后，必须再次检查主窗口和资料归属是否仍有效。

文件管理器显示和外部打开继续使用本地原件，不弹保存对话框、不下载替代品、不改写原件。本地原件缺失时显式失败，用户仍可下载。HTML 与图片保留既有外部打开范围；macOS 与 Windows 分别处理路径、文件管理器及浏览器启动，不放宽 renderer 权限。

资料库数据沿用品牌 Desktop 数据根，升级和重启保留。模块错误不阻断其他 Broker consumer，退出解除订阅、计时器和 IPC。首次创建数据库仍发生在可信访问、推送或连接就绪后的同步阶段，不改变首次安装检测。
