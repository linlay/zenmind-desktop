# 企业聊天

## 文档定位

本文描述 Desktop 企业聊天客户端的系统边界、认证、消息流和远程动作安全模型。HTTP/WS 字段、文件限制、UI 交互和服务端存储实现以各自源码及测试为准。

## 系统边界

`zenmind-im-server` 是独立部署的外部服务，负责用户、会话、消息、附件绑定、可靠事件和在线状态。Desktop 不安装、启动、停止、备份或迁移该服务，也不决定其 SQLite、PostgreSQL 或对象存储实现。

Desktop 负责：

- 使用企业 SSO 身份换取短期 IM session。
- 建立 HTTP 与 WebSocket 客户端，维护本机投影和重连。
- 提供聊天浮层、附件、截图和本地资料体验。
- 在用户确认后执行受限的 Desktop Action 请求。
- 保存设备侧幂等账本和待投递结果，不保存服务端聊天事实副本。

## 认证与连接

```text
Desktop canonical SSO
  -> main 向 IM Server 换取短期 session
  -> 获取一次性 WebSocket ticket
  -> 建立同步连接
  -> bootstrap 会话与历史
  -> 使用可靠事件 cursor 增量更新
```

长期 JWT、短期 session token 和 ticket 只停留在 main。preload 与 renderer 只接收用户、会话、消息和状态 DTO。远端服务必须使用 TLS；loopback 开发环境可以走显式允许的本地地址。

认证临时不可用时保留可恢复配置，但不继续使用过期派生 token。SSO 完成、退出、账号切换和 Settings 开关变化都会重建或停止当前企业聊天 runtime。

## 消息与附件

消息发送使用稳定客户端 ID，只有同步 ready 后才进入可靠发送。Desktop 可以发送文本、图片和普通文件；文件字节通过 HTTPS 上传，WebSocket 只携带消息与附件引用。

renderer 不直接请求鉴权下载地址。图片预览、文件下载、截图和诊断包都由 main 在权限、大小和内容类型校验后处理。

“发送 Agent Chat”是显式高敏感流程：用户选择并逐次确认后，main 从 Agent Platform 读取原始 JSONL 字节，再作为普通 IM 文件上传。该链路允许内部事件和工具数据，不得与公开对话分享的安全导出混用，也不提供自动导入或恢复。

诊断包只收集 Desktop 明确允许的配置与日志，必须限制文件数量和大小，并脱敏 token、Cookie、私钥、账号、本机路径和聊天正文。

## 远程 Desktop Action

IM Server 只能在受支持的私聊中投递结构化动作请求，不能直接连接 Desktop Action Bridge。请求必须绑定客服身份、目标用户、目标设备、动作、稳定 request id 和有效期。

Desktop main 再次验证会话、发送者、设备、动作白名单、过期时间和本地幂等账本。只有当前设备上的用户确认后才执行；远端说明不能覆盖 Desktop 生成的业务摘要或权限模式。

```text
结构化请求
  -> main 校验并持久化 pending
  -> renderer 展示 Desktop-owned 确认
  -> main 原子占位 executing
  -> 调用 canonical Desktop Action
  -> 先持久化终态，再可靠回传结果
```

断线或发送失败只重试结果回执，不重复执行本地动作。Desktop 在执行中异常退出时，下次启动将其收敛为结果未知的失败终态，而不是自动重跑。

## 本地状态与隐私

Desktop 只保存连接配置、设备侧资料、临时投影和幂等账本。自定义头像和座右铭按 Server、用户和设备范围隔离，不修改企业 SSO 或服务端用户资料。

文件默认通过 Server relay。Desktop 不持续上报内网 IP，也不维护裸 IP 设备目录；未来局域网直传必须显式 opt-in、使用短期能力与端到端校验，并在失败时回退 Server relay。

日志不得记录 token、ticket、消息正文或可用于跨用户关联的原始标识。支持包和下载路径不能暴露给远端操作者。

## 生命周期与失败

- 企业聊天是非核心 runtime，不影响核心服务启动卡。
- 连接失败使用有上限的退避重连，并在同步成功后重新获取必要投影。
- 关闭功能、退出登录或切换账号时清理内存投影、连接和待显示确认。
- 服务端可靠 cursor 用于增量恢复，bootstrap 与会话历史仍是恢复基线。
- 其他 Desktop 的设备状态和会话只能展示，不能借其身份执行本机动作。
