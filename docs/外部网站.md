# 外部网站

## 当前状态

外部网站是 Desktop `webs` 域中的 URL 入口。它保存网站 manifest 与可选的 favicon 缓存，不复制网页内容，也不启动本地后端。外部网站可以绑定 `copilotAgentKey`，并通过排序文件进入导航。

每个网站存储在 `data/webs/websites/<website-id>/website.json`。
已发现的 favicon 会下载为同目录下的 `favicon.<ext>`；该缓存不属于 manifest，也不会随网站导出。

## 核心流程

```text
desktop.website.add
  -> normalize url / label / copilotAgentKey
  -> create website:<id> entryKey
  -> write data/webs/websites/<id>/website.json
  -> update web order
  -> AppShell renders web surface
```

manifest 示例：

```json
{
  "schemaVersion": 2,
  "id": "docs",
  "kind": "website",
  "label": "Docs",
  "url": "https://docs.example.com/",
  "copilotAgentKey": "desktopAssistant",
  "createdAt": "2026-06-10T00:00:00.000Z",
  "updatedAt": "2026-06-10T00:00:00.000Z"
}
```

## 配置与接口

字段规则：

- `id`：小写安全 id，最大 80 字符，默认自动生成。
- `entryKey`：运行时派生为 `website:<id>`。
- `url`：只支持 `http` / `https`，缺省协议时补 `https://`。
- `label`：最长 24 字符，缺省时从 hostname 派生。
- `copilotAgentKey`：可选；非空时作为该 Site 尚无 Copilot 打开记录时的冷启动默认 agent，缺少或空值时动态跟随 Desktop 当前默认 Copilot，manifest 中不展开默认值。每个 Site 分别记录 Dock 开关及最后 agent/chat URL；Agent WebClient 将新建或选中的稳定会话收敛为 `/copilot/:agentKey?chatId=<id>`，Desktop 只保存该安全相对 URL。切换 Site 时只恢复目标 Site 的记录，目标没有记录则不显示 Copilot。用户在 Dock 内实际切换 agent 时只更新当时 active Website 的该字段。
- schema v1 的 `agentKey` 继续作为只读兼容 alias；同时存在时优先使用非空 `copilotAgentKey`。新增、编辑、导出与 Desktop action 输出只产生 canonical 字段，用户选择“默认 Copilot”时删除两个字段。

动作接口：

- `desktop.website.list`
- `desktop.website.add`
- `desktop.website.update`
- `desktop.website.remove`
- `desktop.website.open`

## 约束与注意事项

- 外部网站最大数量当前为 14。
- 相同 URL 不重复添加。
- bootstrap schema v2 的 Website 可直接放在 `webs.items`；条目顺序是新 runtime 的首次侧栏顺序。安装后它与手工添加的网站完全相同，可编辑、删除和排序，不显示环境托管状态。
- 删除网站只删除 `website.json` 所在网站目录，不影响本地网站应用目录。
- 排序 canonical 文件是 `config/webs/order.json`，entryKey 使用 `website:<id>`。
- 侧栏 Sites 分组在网站数据加载完成且列表为空时，居中显示弱化引导文案「将鼠标移到「站点」上，点击 + 添加或导入站点。」（英文 `Hover over Sites and click + to add or import a site.`），避免在启动加载期间闪现空状态。
- 侧栏网站行使用真实 favicon 作为左侧图标。初始显示同站点目录的本地 favicon 缓存；首次打开网站后，WebView 初始主标签页发现的真实 favicon 会在校验后下载到 `favicon.<ext>`，并立即替换 monogram。缓存条目绑定 `website:<id>` 与当前配置 URL，重启后保留；网站被删除或 URL 被修改时，对应缓存自动清除。下载或图标加载失败时回退为站点名/域名首字母 monogram，不显示破损图片占位。
- 已打开的网站（WebView 已挂载）在侧栏行右侧的固定 24px 操作槽位显示绿色状态点（`#10B981`，6px 圆点）。当前激活站点同样显示绿点。hover 或行内聚焦（focus-within）时，绿点在同一槽位原位替换为关闭 `×` 按钮，不新增空白或改变行宽；点击关闭该网站的 WebView 并回到 Sites 空白页。关闭中同一槽位显示 loading 态。绿点/关闭按钮不增加额外 Tab 停靠点。
- 本地 WebApp 保持中性网站图标，并在 runtime 为 `running` 时显示同规格绿色状态点。绿点与现有更多操作按钮共用右侧固定槽位，hover 或行内聚焦时原位切换为更多操作；停止或启动失败时不显示绿点。
