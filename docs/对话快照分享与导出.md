# 对话快照分享与导出

## 职责边界

Agent Platform 从一致读取投影 `ConversationSnapshotV1`，再发现当前 Chat 的分享资源：已发布产物、query/人类 steer 的图片音视频引用、成功图片生成结果和实际 Markdown 媒体。已发布 HTML 只补齐直接媒体属性，不扫描目录、Workspace、CSS 或 JS 依赖。普通候选只读元数据与 MIME 前缀，HTML 按现有限额解析；发现失败写入 `omittedResources`。纯投影不做文件 I/O，HTTP 和工具快照共用同一资源发现出口。

Agent WebClient 维护唯一的只读渲染实现。分享渲染包独立构建，包含模板、manifest、JS、CSS 和字体，由显式发布命令整体替换 Tunnel 当前资源；普通 WebClient Program Bundle 不携带该渲染包。

Desktop 负责鉴权和编排。点击分享入口只在主对话列打开紧凑的选择弹窗，遮罩与轻提示也限制在主对话列，不创建链接；用户选择复制链接、生成二维码或浏览器打开时，常驻 Worker 才从 Platform 读取 Snapshot，再逐个通过 `POST /api/chat/export/resources/read` 按 `chatId + sourceRef` 冻结可用产物；单个附件不可用时省略，并把 Snapshot 附件数组重写为实际冻结结果。Main 以一个 multipart 请求上传该 Snapshot 与相同的资源，新建链接固定永久有效。异步期间选择弹窗保留，当前操作按钮和轻提示显示进度；全部资源成功时选择弹窗关闭；部分资源省略时保留弹窗逐项显示文件名和原因，二维码成功时另行打开独立的可关闭弹窗，不显示原始链接。二维码弹窗支持把 PNG 拷贝到剪贴板，或复用 Desktop 下载能力保存到下载文件夹。任一步操作失败时保留选择弹窗，重试复用本次已创建的链接；重新打开选择弹窗则是新的分享会话。发现与冻结共用一份 `omittedResources`，Worker、service、controller、共享结果契约和两个弹窗原样传递；不再汇总成布尔警告。独立的分享管理页按当前账号读取全部有效分享元数据，并提供返回原对话、复制和直接撤销操作。Desktop 不下载模板、不生成公开分享 HTML；本地 HTML 导出仍由同一 Worker 读取 Snapshot 和 Tunnel 当前模板后组装文件。

二维码 PNG 以对话名称命名，沿用 Desktop 下载路径的非法字符替换与同名避让。拷贝时优先使用浏览器图片剪贴板，失败后调用 Electron 系统剪贴板接口。

二维码中央使用当前 Desktop 品牌生成的应用图标，并以高纠错级别编码；图标绘入二维码 Canvas，拷贝和保存的 PNG 与界面展示一致。

Tunnel 是分享数据与生命周期的事实源。它在数据库保存 Snapshot JSON、分享关系和资源元数据，在 `CONVERSATION_SHARE_RESOURCE_DIR/shares/<shareId>/resources/<resourceId>` 保存实际字节。上传先流式写入同文件系统的 `.staging`，完整校验后原子移动，再提交数据库事务；数据库不保存文件正文或任意文件路径。匿名访问 `/share/{id}` 时使用当前唯一模板生成 HTML。

```text
公开分享：Platform 可见内容/正式产物 -> Snapshot -> Desktop Worker -> Tunnel staging/持久化目录 -> 当前模板 -> HTML
本地导出：Platform Snapshot -> Desktop Worker <- Tunnel 当前模板 -> 本地 HTML
```

renderer 只接收文件结果和分享元数据，不接收 Platform/Tunnel token、Snapshot 或 HTML 字节。

## 协议与语义

`/api/chat/export?format=snapshot` 返回 `ConversationSnapshotV1` JSON 和 `<title>.snapshot.json` 文件名。创建分享的 Tunnel 请求使用 `multipart/form-data`、`X-Conversation-Snapshot-Version: 1`、`X-Conversation-ID` 和 `X-Conversation-Share-Expiration: permanent`；`snapshot` part 保存 Worker 冻结后的 JSON，`attachment:<id>` part 必须与其中的资源声明逐项匹配。Desktop 校验创建响应为非一次性且无到期时间。Desktop 每次创建先读取 Tunnel 正文/附件额度，再由 Worker 读取并冻结。正文只序列化一次，附件元数据超额时从尾部移除对应声明和文件并写入省略原因，只重编码小体积元数据；正文或必要诊断装不下则失败，不重写或截断正文；MIME、长度、Hash、多传、漏传或重复 ID 任一不一致仍由 Tunnel 拒绝。读取旧 V1 时缺少可选大小或 Hash 的附件由 Worker 从实际字节补齐。新增可选字段为节点 `attachmentIds`、HTML 描述符 `mediaRefs`、根级 `omittedResources`；成功与省略 ID 不重叠，所有关联必须可解析。期限用尽时剩余候选逐项标记 timeout。

分享列表使用不带查询参数的 `GET /api/desktop/shares`。Tunnel 按鉴权主体返回其所有会话下仍有效的分享元数据，记录固定包含 `conversationId`，Desktop 据此在分享管理页按会话归组；旧的按 `conversationId` 查询列表协议不再兼容。创建响应中的 `conversationId` 必须与请求一致，避免把错误会话的分享结果展示给用户。

选择弹窗不读取或撤销历史记录；复制和撤销已有链接仍由分享管理页承担。历史有限期、永久和一次性分享记录继续按原字段读取并展示，旧链接由 Tunnel 依照原规则运行；一次性链接由 Tunnel 原子认领浏览器会话，认领后的 30 分钟内同一会话可继续加载页面与附件，其他浏览器得到 404。HEAD 不认领。

浏览器与 Desktop 的本地 HTML 导出从 `CONVERSATION_EXPORT_ASSET_ORIGIN/assets/conversation-export/conversation.template.html` 获取当前模板。模板失败不得回退远程地址或生成部分文件。

公开页统一按 MIME 分派 HTML、图片、音频、视频；其他类型提供下载。HTML 使用独立网络 iframe，`sandbox="allow-scripts"` 且没有同源权限。固定 bootstrap 由当前 manifest 提供 SRI 和匿名 CORS；父页鉴权后仅将该 HTML 和 `mediaRefs` 指向的媒体，通过 guest 创建的文档绑定 MessagePort 交付一次。guest 自行创建 Blob URL 并写入文档，HTTP CSP 持续约束脚本、联网、表单、worker 和子 frame。未冻结的本地媒体显示占位，原始下载不改写。

## Worker 与安全

- Worker 必须是仅依赖 Node 内置模块的自包含产物；不得经领域模块入口间接引入 Electron 主进程运行时。URL 校验等纯策略由基础设施层共享，打包回归需在没有开发依赖的目录中实际启动 Worker。
- Worker FIFO 串行读取 Snapshot；公开分享任务不请求模板，本地 HTML 任务并行请求 Snapshot 和模板。
- Snapshot 请求只接受可信 Platform 回环地址，带短期 bearer token，禁止重定向；模板只接受配置的 Tunnel asset origin，禁止重定向。
- Desktop 模式下，带 app scope、device claim 和非空本地主体的宿主 token 只能通过严格的 `POST /api/chat/export/resources/read` 按 `sourceRef` 跨 owner 读取当前 Chat 允许的分享资源；发布文件仍走 manifest/hash 校验，普通文件仅允许图片音视频；`list/get`、`artifactId` read、Standalone 和通用 `/api/resource` 仍沿用原 owner 边界。
- Worker 按 Platform 响应头读取 Snapshot，附件使用 Tunnel 的独立预算，共用 15 秒期限；模板在 HTTP 读取处执行 256 KiB 保护。HTML 没有独立业务上限，组装与保存不重复检查大小，保留现有安全转义与分配失败提示。Worker 严格检查正文；可选附件在状态、Content-Type、声明长度、实际长度或 SHA-256 不一致时省略。
- 本地 HTML 拼接对 `<`、`>`、`&`、U+2028 和 U+2029 做 JSON Unicode 转义；Tunnel 服务端渲染执行同等安全转义。
- Main 以 transfer list 接收 `ArrayBuffer`，公开分享上传 Snapshot 与已校验附件，本地导出按字节写盘。
- token 不得进入 renderer、URL、日志或错误文本。

## 发布与迁移

分享渲染器随 Tunnel 二进制原子发布。普通 WebClient 发布不会改变分享页面；更新分享渲染器必须显式构建、同步、测试并重新构建 Tunnel。已被历史 HTML 引用的哈希资源继续保留；发布顺序为先部署兼容新旧 V1 的渲染器，再部署 Platform 和 Desktop。

旧 BLOB 库迁移时先停止 Tunnel 并备份数据库和资源目录。启动迁移逐条校验旧正文的大小和 SHA-256，经 staging 原子写入分享资源目录，再在事务中复制元数据、删除旧 BLOB 表并升级 SQLite schema 版本；迁移可安全重跑。运行时只读文件目录，不保留 BLOB 回退。

撤销先使数据库记录不可访问，再删除目录；到期资源和一次性认领会话失效资源由启动及每小时清理回收。删除失败时保留元数据供下轮重试，未认领的一次性分享和永久分享不会被提前清理。

## 验收

验证打开操作栏不创建链接，三项操作按需上传，失败重试复用已创建链接；创建请求上传的 Snapshot 附件声明与实际冻结附件完全一致，正文在附件失效时仍可分享，响应会话身份一致且为永久分享。账号级列表不携带查询参数，只返回当前所有者在所有会话下仍有效且包含 `conversationId` 的元数据。管理页直接撤销；旧记录的到期和一次性会话语义符合约定，公开页面按 MIME 预览，验证 HTML 一次交付、原生媒体 Range/HEAD 和失败占位。更新分享渲染包后分享统一使用当前模板展示。覆盖 `</script>`、`<`、`&`、U+2028/U+2029，构建及测试结果、环境限制以 Tunnel 的 `docs/conversation-share-rendering/08-execution-record.md` 为准。
