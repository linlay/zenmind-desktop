# 对话快照分享与导出

## 文档定位

本文描述 Markdown、本地静态 HTML 和公开分享共同使用的对话快照边界。精确字段、模板标记、大小常量、IPC 类型和文件名规则以 Agent Platform、Agent WebClient、Desktop 与 Tunnel 源码及测试为准。

## 职责边界

Agent Platform 是对话语义与数据的所有者。它从一次一致读取中投影 `ConversationSnapshotV1`，同一份序列化 JSON 字节用于 20 MiB 校验和 Snapshot 响应；Markdown 也只消费该结构体。Platform 不加载模板、不生成 HTML，也不理解资源域名或分享生命周期。

Agent WebClient 是静态 HTML 展示实现的唯一所有者。它构建并提供 `/export/conversation.template.html`、React 导出运行时、CSS、字体和 Tunnel 静态资源。模板保持一个 Snapshot 标记和至少一个资源域名标记，Host 对模板返回 `Cache-Control: no-store`。

Desktop main 是本地编排者。一个随应用常驻的 `worker_threads` Worker 同时服务本地 HTML 导出与公开分享；Worker 从正在运行的 Platform 读取 Snapshot、从正在运行的 WebClient 读取模板，完成校验、缓存、转义和字节拼接。Main 不读取大体积 Snapshot、不解析模板，也不做大字符串或 `Buffer.concat`。

Tunnel 是分享生命周期的唯一事实源。它把 Desktop 生成的 HTML 当作不透明字节保存并返回，同时托管内容寻址的导出运行时资源；它不解释 Snapshot、消息或模板。

```text
Platform /api/chat/export?format=snapshot ─┐
                                          ├─> Desktop 常驻 Worker ─> HTML ArrayBuffer
WebClient /export/conversation.template.html ┘          ├─> 本地文件
                                                        └─> Tunnel 分享 BLOB

列表：renderer -> IPC -> Desktop main -> Tunnel GET
撤销：renderer -> IPC -> Desktop main -> Tunnel DELETE
```

renderer 只接收文件结果和分享元数据，不接收 Platform/Tunnel token、私有 header、Snapshot 或 HTML 字节。

## 导出与分享语义

`/api/chat/export` 的空格式和 `format=markdown` 返回 Markdown；`format=snapshot` 返回原始 `ConversationSnapshotV1` JSON 和 `<title>.snapshot.json` 文件名。`format=html` 与资源域名 Header 不存在。

Markdown 只包含每个已完成 root turn 的用户问题和最后一个 assistant 最终回答，不包含标题、reasoning、工具过程、运行状态或 ID。Snapshot 可以表示请求时已持久化的运行中、取消和失败轮次；生成的静态 HTML 不会继续更新。

本地导出与分享必须调用同一个 Desktop HTML Render Service。创建分享时，main 先验证 `chatId`、时效、当前登录和 Tunnel target，再取得 Platform 短期 token、Platform/WebClient 回环地址及 WebClient 版本并向 Worker 提交任务；生成成功后才把同一份 HTML Buffer POST 到 Tunnel。生成失败不得调用 Tunnel 或创建空记录，不提供 Platform HTML 回退、临时 Worker、Main 拼接或旧事件流兼容路径。

Desktop 每次打开分享弹窗都直接查询 Tunnel，只展示当前会话仍有效的分享元数据。创建成功后插入当前列表，撤销成功后移除；列表失败不阻断创建。有限链接在有效、未撤销且未到期时允许匿名读取，永久链接没有自动到期时间但仍可主动撤销。一次性链接没有时间到期点，首次合法公开 GET 由 Tunnel 原子取得并物理删除记录；并发请求只有一个返回正文，后续访问与未知、过期或撤销链接一样返回 404。链接预览器、机器人和安全扫描器发出的 GET 也会消费一次性链接，HEAD 与其他方法不会消费。已经下载或开始返回的副本不在召回保证内；取得消费权后即使客户端中途断网，链接也不会恢复。

WebClient 页面内直接导出 HTML 时并行请求同源 Snapshot 和模板。Snapshot 全程保持 Blob，不做 `JSON.parse`、`JSON.stringify` 或大字符串转换；浏览器使用 Blob parts 插入 Snapshot 和资源域名。

## Worker 与性能

- 应用 ready 后预启动一个 Worker；任务 FIFO 串行，避免并发保留多份 20 MiB Snapshot 与 HTML。退出时终止 Worker并拒绝未完成任务；崩溃后在下一任务前重建。
- 冷缓存时并行请求 Snapshot 和模板。两者只允许 Service Manager 给出的可信回环地址，禁止重定向；Snapshot 超时 15 秒、上限 20 MiB，模板超时 5 秒、上限 256 KiB。
- Worker 严格检查 HTTP 状态、Content-Type、声明长度和实际长度。Platform bearer token 仅进入请求头，不写日志、不缓存、不进入错误对象。
- Worker 只缓存一份已解析模板，键为 `WebClient origin + service version`；地址或版本改变后自动失效。不缓存 Snapshot 或最终 HTML。
- 拼接使用字节级单次分配：原生 `Buffer.indexOf` 定位标记和危险字节，先计算精确输出长度，超过 20 MiB 时在分配前拒绝，再直接把模板片段、资源域名和转义后的 Snapshot 写入一个 `ArrayBuffer`。
- `<`、`>`、`&`、U+2028 和 U+2029 直接写成 JSON Unicode 转义，不创建第二份转义字符串。Worker 用 transfer list 把 ArrayBuffer 所有权交回 Main；Main 用 `Buffer.from(arrayBuffer)` 零拷贝包装后落盘或上传。
- Worker 不完整解析 Snapshot。业务结构由 Platform 构建保证，打开 HTML 时由 WebClient 导出运行时执行 Snapshot V1 严格校验。
- 20 MiB 预热性能验收至少连续运行 20 次：Worker 拼接 p95 不超过 30 ms，Electron Main 事件循环最大额外阻塞不超过 10 ms。若不达标，只优化 Worker 字节算法。

## 静态 HTML 与公开访问

Snapshot JSON 通过模板唯一 marker 注入，不使用 Base64。模板内部不包含 `<style>` 或可执行内联脚本，唯一带正文的 script 是 `type="application/json"` 的 Snapshot。导出文档是独立只读运行时，不装配主应用鉴权、Desktop Bridge、WebSocket 或业务 API。

公开访问由 Tunnel 在 `/share/{id}` 以 `text/html; charset=utf-8` 返回落库字节，并在 `/assets/conversation-export/{assetSet}/` 返回编译期白名单资源。普通分享走主键只读查询；一次性分享在普通查询未命中后使用 SQLite `DELETE ... RETURNING` 原子取得正文，不增加消费表、后台任务或正文副本。模板只固定内容哈希路径，不固定域名；Desktop Worker 注入当前 Tunnel origin。生产只接受 HTTPS，本地开发只额外接受 loopback HTTP。HTML 使用 `no-store`，内容寻址 JS/CSS/font 使用一年 immutable、SRI、CORS/CORP 与 `nosniff`。

## 安全与发布不变量

- Platform token 只用于 Worker 到 Platform 的标准 `Authorization`；Tunnel site token 只用于 Desktop 到 Tunnel。二者不得进入 renderer、URL、日志或错误文本。
- Snapshot URL、模板 URL 和资源 origin 分别执行严格来源与路径校验；网络请求禁止重定向，避免 token 或模板请求被转发。
- Tunnel 公共接口设置 no-store、nosniff、noindex 与 no-referrer；列表仅读取元数据，不读取 HTML。
- macOS 与 Windows 使用 Electron Downloads 路径，其他平台使用 Home 回退；HTML 与 Markdown 都按字节写入，不做换行转换，复用文件名清洗和不覆盖重名文件策略。
- WebClient Program Bundle 包含模板；模板不再同步到 Platform。Tunnel 资源仍按 asset-set 追加式发布，永久分享引用的 hash 不得覆盖或清理。
- Platform、WebClient、Desktop 和 Tunnel 不保留双路径、Feature Flag 或旧 HTML API 兼容代码；版本不匹配或核心服务不可用时明确失败。

## 手工回归

在 macOS 与 Windows 分别验证：未登录或 Tunnel 未启用时创建在渲染前失败；WebClient 模板不可用时导出和分享明确失败；登录后本地导出与公开分享生成完全一致的 HTML；六种有效期的创建、列表刷新和撤销正常；一次性链接首次 GET 成功、并发只成功一次、HEAD 不消费、再次 GET 返回 404。全过程确认 Main 事件循环无明显卡顿，renderer、Platform、WebClient、Desktop 与 Tunnel 日志和错误文案均不出现 token。
