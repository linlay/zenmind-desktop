# 对话快照分享与导出

## 文档定位

本文描述公开分享与本地静态 HTML 导出共同使用的对话快照边界。精确事件字段、模板路径、大小常量、IPC 类型和文件名规则以 Agent Platform、Agent WebClient 与 Desktop 源码及测试为准。

## 共同快照与职责

Agent Platform 是导出与分享的唯一编排者。它从同一次一致读取中投影 `ConversationSnapshotV1`，并基于该快照生成 Markdown 或完整 HTML。消费者不得从原始 JSONL、运行日志、renderer 状态或公开分享字节重新解释事件语义。

```text
Agent Platform Summary + LoadChat
  -> ConversationSnapshotV1
  -> Markdown / 完整 HTML
  -> 分享时将同一个 HTML Buffer 上传 Tunnel
  -> Tunnel /share/{id} 直接返回同一份 HTML 主文档
```

- Agent WebClient 拥有 HTML 模板、严格 Snapshot parser、只读 UI 与静态资源策略；同一次构建生成轻量模板和内容寻址资产集，模板由 Platform 打包并在启动时校验缓存，资产集由 Tunnel 追加式托管。
- Tunnel 保存不透明 HTML 字节、owner、会话关联、到期、撤销和最近访问状态，不解析标题、消息、Markdown 或事件；最近访问与 HTML BLOB 分表。
- Desktop 只负责用户动作、SSO site token、Tunnel API origin、Platform bridge、文件落盘和结果交互；不生成 HTML、不直接访问 Tunnel 数据面。
- renderer 只接收文件结果和公开分享元数据，不接收 Tunnel token、origin、私有 header、快照或 HTML 字节。

## 导出与分享语义

Markdown 只包含每个已完成 root turn 的用户问题和最后一个 assistant 最终回答，不包含标题、reasoning、工具过程、运行状态或 ID。HTML 可以呈现请求时已持久化的运行中、取消和失败轮次，但不会在导出后继续更新。

本地 HTML 导出由 Desktop 请求 Platform 的 HTML 格式并将响应 Buffer 原样写入系统下载目录。公开分享由 Desktop main 把当前 Tunnel origin 与短期站点授权通过私有 header 交给 Platform；renderer 只通过受限业务枚举选择 `5m`、`30m`、`1h`、`3h`、`1d`、`5d`、`15d`、`30d` 或 `permanent`，默认 `30d` 且每次打开弹窗重置。Platform 完整生成并校验 HTML 后把枚举通过受控 Header 传给 Tunnel。生成失败不得创建空分享记录，Desktop 不回退旧事件流协议或本地模板拼装。

Desktop 每次打开分享弹窗都由 Platform 查询 Tunnel，只展示当前会话仍有效的分享元数据；列表不是 Desktop 本地历史或 Platform 缓存。创建成功后直接把返回记录插入当前列表，撤销成功后移除；列表失败不阻断创建，也不轮询或建立 SSE。撤销时 Desktop 重新读取当前登录和 Tunnel 配置，再由 Platform 调用 Tunnel。链接本身是随机 bearer grant；有限链接在有效、未撤销且未到期时允许匿名读取，永久链接没有自动到期时间但仍可主动撤销。撤销或到期后的新请求统一不可访问。已经下载的副本不在召回保证内。创建成功后时效不可修改，变更需撤销并重新创建。

## 静态 HTML 与公开访问

Snapshot JSON 以 HTML escaping 后的 JSON 字节注入模板唯一 marker，不使用 Base64。模板内部不包含 `<style>` 或可执行内联脚本，唯一带正文的 script 是 `type="application/json"` 的 Snapshot；初始 DOM、外部 CSS link 和外部 deferred runtime script 之外不再承载显示实现。导出文档是独立只读运行时，不装配主应用鉴权、Desktop Bridge、WebSocket 或业务 API。

公开访问由 Tunnel 在 `/share/{id}` 以 `text/html; charset=utf-8` 直接返回落库字节，并在 `/assets/conversation-export/{assetSet}/` 返回编译期白名单显示资源；两者都不经过运行中的 WebClient 或 Desktop。模板只固定内容哈希路径，不固定域名；Desktop 将当前 Tunnel origin 传给 Platform，Platform 在渲染分享或导出 HTML 时同时注入资源 URL 与 CSP。生产只接受 HTTPS，本地开发只额外接受 loopback HTTP。HTML 使用 `no-store`，内容寻址 JS/CSS/font 使用一年 immutable、SRI、CORS/CORP 与 `nosniff`。

## 文件、性能与平台

- Snapshot JSON 与最终 HTML 在生成和写入边界执行大小复核；公开 GET 信任已落库字节，不重复解析或净化。
- 分享列表只读取带所有者与会话索引的元数据，不读取 HTML；访问仅保存最后一个时间点，不保存日志、计数或分析事件。
- 分享只生成一个 HTML Buffer，并由 Platform 原样上传；Desktop 不做事件扫描、Base64 或模板读取。
- `30d` 固定为 720 小时而非自然月；永久分享在各信任边界都必须用明确的 `expiresAt: null` 表达。
- Tunnel 的 RFC3339 分享时间只允许 Platform adapter 解析一次；Desktop main、preload 与 renderer 使用统一 epoch milliseconds，尚未访问明确为 `lastAccessedAt: null`。
- macOS 与 Windows 使用 Electron 的 Downloads 路径，其他平台使用 Home 回退；所有平台复用文件名清洗和不覆盖重名文件策略。
- HTML 与 Markdown 都按 Buffer 写入，不做平台换行转换。Windows 保留名与分隔符、macOS Unicode 和重名后缀继续由共用路径工具处理。

## 安全与发布不变量

- Platform token 只放标准 `Authorization`；Tunnel token 和 origin 只放约定私有 header，且不得进入 renderer、URL、日志或错误文本。
- 静态导出和公开分享使用同一 HTML renderer；系统提示、Token、工具原始数据和本地路径不得进入 Snapshot。
- Tunnel 公共接口直接返回 `text/html; charset=utf-8`，并设置 no-store、nosniff、noindex 与 no-referrer 策略。
- Desktop 不读取 WebClient 安装目录，不向 Tunnel POST/DELETE，不保留旧事件流兼容路径。
- 发布时由 WebClient 一次构建模板与 asset-set，先把不可变资产追加到 Tunnel 并探测成功，再发布引用该 hash 的 Platform 模板，最后按正常节奏发布 Desktop。回滚 Platform 时保留新旧资产集；已被永久分享引用的 hash 不得覆盖或清理。不兼容时明确失败，不双写、双读或降级旧协议。
