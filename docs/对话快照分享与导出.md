# 对话快照分享与导出

## 职责边界

Agent Platform 负责从一致读取生成 `ConversationSnapshotV1`。它不加载模板、不生成分享 HTML，也不理解分享生命周期。

Agent WebClient 维护唯一的只读渲染实现。分享渲染包独立构建，包含模板、manifest、JS、CSS 和字体，由显式发布命令整体替换 Tunnel 当前资源；普通 WebClient Program Bundle 不携带该渲染包。

Desktop 负责鉴权和编排。创建公开分享时，常驻 Worker 只从 Platform 读取 Snapshot，Main 将原始 Snapshot bytes 上传到 Tunnel；不下载模板、不生成分享 HTML。本地 HTML 导出仍由同一 Worker 读取 Snapshot 和 Tunnel 当前模板后组装文件。

Tunnel 是分享数据与生命周期的事实源。它保存 Snapshot JSON，匿名访问 `/share/{id}` 时使用当前唯一模板生成 HTML，并只提供当前 manifest 对应的内容 Hash 资源。

```text
公开分享：Platform Snapshot -> Desktop Worker -> Tunnel JSON -> 当前模板 -> HTML
本地导出：Platform Snapshot -> Desktop Worker <- Tunnel 当前模板 -> 本地 HTML
```

renderer 只接收文件结果和分享元数据，不接收 Platform/Tunnel token、Snapshot 或 HTML 字节。

## 协议与语义

`/api/chat/export?format=snapshot` 返回原始 `ConversationSnapshotV1` JSON 和 `<title>.snapshot.json` 文件名。创建分享的 Tunnel 请求使用 `Content-Type: application/json`、`X-Conversation-Snapshot-Version: 1`、`X-Conversation-ID` 和 `X-Conversation-Share-Expiration`，正文上限为 20 MiB。不保留 HTML 上传、旧 Header 或旧字段兼容路径。

Desktop 每次打开分享弹窗直接查询 Tunnel，只展示当前会话仍有效的元数据。有限、永久、撤销和一次性语义不变；一次性链接由 Tunnel 使用 `DELETE ... RETURNING` 原子消费，并发仅一个 GET 成功。HEAD 不消费。

浏览器与 Desktop 的本地 HTML 导出从 `CONVERSATION_EXPORT_ASSET_ORIGIN/assets/conversation-export/conversation.template.html` 获取当前模板。模板失败不得回退远程地址或生成部分文件。

## Worker 与安全

- Worker FIFO 串行读取 Snapshot；公开分享任务不请求模板，本地 HTML 任务并行请求 Snapshot 和模板。
- Snapshot 请求只接受可信 Platform 回环地址，带短期 bearer token，禁止重定向；模板只接受配置的 Tunnel asset origin，禁止重定向。
- Snapshot 上限 20 MiB，模板上限 256 KiB，最终本地 HTML 上限 20 MiB。Worker 严格检查状态、Content-Type、声明长度和实际长度。
- 本地 HTML 拼接对 `<`、`>`、`&`、U+2028 和 U+2029 做 JSON Unicode 转义；Tunnel 服务端渲染执行同等安全转义。
- Main 以 transfer list 接收 `ArrayBuffer`，公开分享原字节上传，本地导出按字节写盘。
- token 不得进入 renderer、URL、日志或错误文本。

## 发布与迁移

分享渲染器随 Tunnel 二进制原子发布，只保留当前模板、manifest 和 asset-set。普通 WebClient 发布不会改变分享页面；更新分享渲染器必须显式构建、同步、测试并重新构建 Tunnel。

旧库迁移时先停止 Tunnel 并备份 SQLite。一次性工具从每条旧 HTML 严格提取唯一 V1 Snapshot，在单事务中重建分享表；任一记录失败则整体回滚。迁移保留分享 ID、所有者、会话、创建/到期/撤销时间、一次性标记和访问元数据。部署校验完成后删除迁移工具。

## 验收

验证创建请求上传 JSON；旧分享 ID 迁移后内容一致；撤销、到期和一次性语义不变；公开页面只请求当前存在且返回 200 的资源。发布普通 WebClient 后已有分享仍可访问；更新分享渲染包后旧分享由当前模板正常展示。覆盖 `</script>`、`<`、`&`、U+2028/U+2029，并确认三端 test/build 通过、旧资源目录和兼容分支为零。
