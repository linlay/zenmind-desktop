# 对话快照分享与导出

## 职责边界

Agent Platform 负责从一致读取生成 `ConversationSnapshotV1`。`.tools/artifacts.json` 是分享资源的唯一清单；Platform 只接受 `artifacts/<runId>/<file>` 普通文件，并根据实际文件生成名称、MIME、大小和 SHA-256。它不加载模板、不生成分享 HTML，也不理解分享生命周期。

Agent WebClient 维护唯一的只读渲染实现。分享渲染包独立构建，包含模板、manifest、JS、CSS 和字体，由显式发布命令整体替换 Tunnel 当前资源；普通 WebClient Program Bundle 不携带该渲染包。

Desktop 负责鉴权和编排。创建公开分享时，常驻 Worker 从 Platform 读取 Snapshot，再逐个通过 `/api/resource` 读取并校验 Snapshot 声明的全部正式产物；Main 以一个 multipart 请求上传原始 Snapshot bytes 和资源。创建弹窗只负责选择有效期、创建并展示本次生成的链接。独立的分享管理页按当前账号读取全部有效分享元数据，并提供返回原对话、复制和撤销操作。Desktop 不下载模板、不生成公开分享 HTML；本地 HTML 导出仍由同一 Worker 读取 Snapshot 和 Tunnel 当前模板后组装文件。

Tunnel 是分享数据与生命周期的事实源。它在数据库保存 Snapshot JSON、分享关系和资源元数据，在 `CONVERSATION_SHARE_RESOURCE_DIR/shares/<shareId>/resources/<resourceId>` 保存实际字节。上传先流式写入同文件系统的 `.staging`，完整校验后原子移动，再提交数据库事务；数据库不保存文件正文或任意文件路径。匿名访问 `/share/{id}` 时使用当前唯一模板生成 HTML。

```text
公开分享：Platform manifest/正式产物 -> Snapshot -> Desktop Worker -> Tunnel staging/持久化目录 -> 当前模板 -> HTML
本地导出：Platform Snapshot -> Desktop Worker <- Tunnel 当前模板 -> 本地 HTML
```

renderer 只接收文件结果和分享元数据，不接收 Platform/Tunnel token、Snapshot 或 HTML 字节。

## 协议与语义

`/api/chat/export?format=snapshot` 返回原始 `ConversationSnapshotV1` JSON 和 `<title>.snapshot.json` 文件名。创建分享的 Tunnel 请求使用 `multipart/form-data`、`X-Conversation-Snapshot-Version: 1`、`X-Conversation-ID` 和 `X-Conversation-Share-Expiration`；`snapshot` part 保存 JSON，`attachment:<id>` part 必须与 Snapshot 的资源声明逐项匹配。Snapshot 与全部资源累计分别最多 20 MiB；MIME、长度、Hash、多传、漏传或重复 ID 任一不一致都整体失败。不保留 JSON-only 上传、旧 Header、旧版本或旧字段兼容路径。

分享列表使用不带查询参数的 `GET /api/desktop/shares`。Tunnel 按鉴权主体返回其所有会话下仍有效的分享元数据，记录固定包含 `conversationId`，Desktop 据此在分享管理页按会话归组；旧的按 `conversationId` 查询列表协议不再兼容。创建响应中的 `conversationId` 必须与请求一致，避免把错误会话的分享结果展示给用户。

分享弹窗不读取或撤销历史记录；复制和撤销已有链接统一由分享管理页承担。有限、永久、撤销和一次性语义不变；一次性链接由 Tunnel 原子认领浏览器会话，认领后的 30 分钟内同一会话可继续加载页面与附件，其他浏览器得到 404。HEAD 不认领。

浏览器与 Desktop 的本地 HTML 导出从 `CONVERSATION_EXPORT_ASSET_ORIGIN/assets/conversation-export/conversation.template.html` 获取当前模板。模板失败不得回退远程地址或生成部分文件。

## Worker 与安全

- Worker FIFO 串行读取 Snapshot；公开分享任务不请求模板，本地 HTML 任务并行请求 Snapshot 和模板。
- Snapshot 请求只接受可信 Platform 回环地址，带短期 bearer token，禁止重定向；模板只接受配置的 Tunnel asset origin，禁止重定向。
- Snapshot 上限 20 MiB，全部分享资源累计上限 20 MiB，模板上限 256 KiB，最终本地 HTML 上限 20 MiB。Worker 严格检查状态、Content-Type、声明长度、实际长度和 SHA-256。
- 本地 HTML 拼接对 `<`、`>`、`&`、U+2028 和 U+2029 做 JSON Unicode 转义；Tunnel 服务端渲染执行同等安全转义。
- Main 以 transfer list 接收 `ArrayBuffer`，公开分享上传 Snapshot 与已校验附件，本地导出按字节写盘。
- token 不得进入 renderer、URL、日志或错误文本。

## 发布与迁移

分享渲染器随 Tunnel 二进制原子发布，只保留当前模板、manifest 和 asset-set。普通 WebClient 发布不会改变分享页面；更新分享渲染器必须显式构建、同步、测试并重新构建 Tunnel。

旧 BLOB 库迁移时先停止 Tunnel 并备份数据库和资源目录。启动迁移逐条校验旧正文的大小和 SHA-256，经 staging 原子写入分享资源目录，再在事务中复制元数据、删除旧 BLOB 表并升级 SQLite schema 版本；迁移可安全重跑。运行时只读文件目录，不保留 BLOB 回退。

撤销先使数据库记录不可访问，再删除目录；到期资源和一次性认领会话失效资源由启动及每小时清理回收。删除失败时保留元数据供下轮重试，未认领的一次性分享和永久分享不会被提前清理。

## 验收

验证创建请求上传 Snapshot 与全部冻结附件且响应会话身份一致；账号级列表不携带查询参数，只返回当前所有者在所有会话下仍有效且包含 `conversationId` 的元数据；分享弹窗仅创建链接，分享管理页负责分组、返回仍存在的原对话、复制和撤销，无法解析原对话身份时不得误导航。撤销、到期和一次性会话语义符合约定；公开页面只请求当前存在且返回 200 的资源。更新分享渲染包后分享统一使用当前模板展示。覆盖 `</script>`、`<`、`&`、U+2028/U+2029，并确认三端 test/build 通过、旧资源目录和兼容分支为零。
