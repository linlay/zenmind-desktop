# 时间契约

## 文档定位

本文定义 Desktop 跨 main、preload、renderer 和 shared contract 的时间表示原则。验证函数、类型实现和历史字段基线以源码及测试为准。

## 统一表示

Desktop 内部的具体时间点统一使用 Unix epoch milliseconds，并通过 `EpochMilliseconds` 表达。边界输入必须是 `Date` 和 `Intl` 可表示范围内的安全整数。

- 必填时间缺失或非法时直接报告 contract violation。
- 可选时间只用 `undefined` 或显式 `null` 表示缺失，不接受空字符串。
- renderer 只在最终展示时格式化时间，不在展示层兼容解析上游文本。
- 新 shared contract 的 `*At` 或 `*timestamp` 字段不得使用模糊字符串。

## 外部协议边界

外部协议明确要求 RFC3339 时可以保留文本，但字段名和协议说明必须表明其字符串语义。进入 Desktop shared contract 前应在所属 adapter 中完成验证和转换。

JWT 的 `iat`、`exp` 按 Unix seconds 解析，只在认证边界内部存在；离开 JWT 校验后必须转换为 epoch milliseconds。通用验证器不根据数值大小猜测秒或毫秒。

历史字符串时间只在显式兼容 adapter 中读取。迁移某个 DTO 时同步缩减静态兼容基线，不新增宽松解析。

## 禁止行为

- 不用 `Date.parse` 或 `new Date(string)` 静默兼容未知文本。
- 不用当前时间、`0` 或猜测值填补非法必填时间。
- 不把 Unix seconds 直接当作 milliseconds。
- 不在 Desktop 侧改写远端服务的存储时间；只在边界验证和报告。
- 不让同一字段在不同进程中同时支持 number 与 string 两套语义。
