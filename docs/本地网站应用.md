# 本地网站应用

## 当前状态

本地网站应用是 Desktop `webs` 域中的可运行本地应用。它包含 `webapp.json` 和静态前端目录；Node 后端是可选项。纯前端应用由 Desktop 直接启动本地 HTTP server；全栈应用额外启动 Node 后端，并把 API 前缀代理到后端。

每个网站应用存储在 `data/webs/webapps/<webapp-id>/`。

## 核心流程

```text
webapp.json
  -> readWebappItemFromDir()
  -> webappRuntime.start()
  -> optional: reserve backend port / spawn node backend / wait healthPath
  -> start frontend static server on 127.0.0.1
  -> write state/webs/webapps/<id>/runtime.json
```

运行期环境变量：

- `HOST=127.0.0.1`
- `PORT=<backend-port>`
- `WEBAPP_ID`
- `WEBAPP_ROOT`
- `WEBAPP_STATE_DIR`
- `WEBAPP_LOG_DIR`
- `DESKTOP_ACTION_BRIDGE_URL`：当前 Desktop 本地动作桥地址，供 WebApp Node 后端调用明确开放的 Desktop 能力。

## 配置与接口

`webapp.json` 关键字段：

- `id`、`kind`、`label`、`agentKey`。
- `frontend.root`：静态前端根目录，默认 `frontend`。
- `frontend.index`：入口 HTML，默认 `index.html`。
- `frontend.spa`：是否启用 SPA fallback，默认 true。
- `frontend.apiPrefix`：需要代理到后端的 API 前缀，默认 `/api`。
- 可选 `backend`：省略时是纯前端应用；提供时 `runtime` 只支持 `node`，并配置 `entry`、`args`、`env`、`port`、`healthPath`。

动作接口：

- `desktop.web.webapp.getStatus`
- `desktop.web.webapp.start`
- `desktop.web.webapp.stop`
- `desktop.web.webapp.restart`
- `desktop.web.webapp.open`
- `desktop.web.webapp.installAndOpen`

## 约束与注意事项

- `frontend` 和可选 `backend` 路径必须是 webapp 根内的安全相对路径，禁止绝对路径、`..` 和隐藏段。
- 静态 server 只监听 `127.0.0.1`。
- 非 API 请求走静态文件；匹配 `frontend.apiPrefix` 的请求代理到后端。
- 日志写入 `logs/webs/webapps/<id>/main.log` 和 `error.log`。
- WebApp 不读取 Desktop token 或模型密钥；纯前端与全栈页面都可通过同源 `POST /__desktop/actions/call` 使用明确开放的助理动作。该路径只接受匹配当前 loopback WebApp 的 Origin，Tunnel 公网页面不能借此消费本机模型。
- 打包 demo 由 `DEMO=true` 控制，当前模板 id 为 `demo-node-html`。
