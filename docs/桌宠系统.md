# 桌宠系统

## 当前状态

Desktop 桌宠是独立小窗能力，支持内置品牌桌宠、用户导入桌宠、agent 绑定、未读/运行任务状态、预览面板和手动 signature 动作。

配置保存到 `config/desktop/pet.json`，运行状态保存到 `state/desktop/pet-state.json`，用户资产保存到 `data/pets/<pet-id>/`。

## 核心流程

```text
pet settings
  -> desktop-pet runtime
  -> pet window
  -> agent-platform status / stream
  -> unread, awaiting, running task count
  -> state file + renderer updates
```

窗口模式：

- `base`
- `bubble`
- `preview-collapsed`
- `preview-expanded`
- `task-list-compact`
- `task-list`

标准状态包括 idle、jumping、moving-left、dragging、done、failed、running、awaiting、review。

## 配置与接口

桌宠设置核心字段：

- `enabled`
- `appearanceId`
- `selectedPetId`
- `boundAgentKey`
- `position`
- `window.edgeDock`
- `window.previewExpanded`

桌面动作：

- `desktop.pet.state`：返回当前运行状态。顶层只有 `enabled` 表示桌宠窗口当前真实可见，不存在顶层 `visible`。
- `desktop.pet.show`：幂等显示桌宠；只有窗口确认显示后才返回 `enabled: true`。创建或显示失败时销毁窗口、停止状态客户端、清理临时状态并将配置回写为 `enabled: false`。
- `desktop.pet.hide`：幂等销毁桌宠窗口、停止状态客户端并清理预览和未读状态，返回 `enabled: false`。
- `desktop.pet.list`：返回当前形象和可用形象列表。
- `desktop.pet.set`：只切换形象，接受 `appearanceId` 或 `id`。

`pet.json` 中的 `enabled` 仍是下次启动是否恢复桌宠的持久化配置，不需要迁移。但公开 `DesktopPetState.enabled` 是运行态：启动恢复期间窗口显示前必须为 `false`，显示成功后才变为 `true`；失败时持久化配置回退为 `false`。普通关闭、右键关闭、托盘关闭和设置页开关必须复用同一套 show/hide 生命周期。应用退出可以隐藏窗口并保留下次启动配置，但此时发布的运行状态不能继续声称桌宠已显示。

`previewPanel.visible` 只表示桌宠内部预览面板是否显示，与桌宠窗口本身是否显示无关，继续保留。

## 时间契约

桌宠的任务、消息、预览项和状态快照沿用助理 IPC 的 `EpochMilliseconds` 契约，不在主进程转换为 ISO 字符串。状态 WebSocket 仅对 `frame: "push"` 应用助理集成中的按类型字段表：run 使用 `startedAt` / `finishedAt`，未读使用 `createdAt`，已读使用 `readAt`，`chat.read_all` 不带时刻并保留当前状态的 `updatedAt`；非 heartbeat 的 `data.timestamp` 会被拒绝并触发刷新。桌宠 SSE 与 `frame: "stream"` 预览仍使用事件 `timestamp`。缺失、字符串、秒级、负数或浮点的必填 push 时刻会被忽略并触发状态刷新，不会以本机当前时间替代。桌宠 UI 如需显示时间，仅在渲染时格式化该值。完整规则见[时间契约](时间契约.md)。

## 约束与注意事项

- `boundAgentKey` 是运行绑定，长期用户偏好和运行状态需要分清。
- 不得重新引入顶层 `visible`，也不新增 `setEnabled`、`setAppearance` 或 `setBoundAgent` Desktop Action。
- 用户桌宠资产通过 `desktop-pet` 专用 asset protocol 读取，不直接拼未校验文件 URL。
- 桌宠窗口位置需要按当前 display workArea clamp，拖拽和 edge dock 行为要显式处理。
- 拖动展开面板的桌宠时，面板可在移动期间临时隐藏，但必须保持桌宠图标可见；松手后在新位置恢复原有的聊天框、任务列表或预览面板。
- 新增桌宠外观必须包含 required state keys，并满足标准动作帧数约束。
