# 桌面协议与动作桥

## 当前状态

Desktop 暴露两类本地自动化协议：

- HTTP action bridge：本地 `127.0.0.1:11788`。
- Desktop WebSocket：默认 `ws://127.0.0.1:7082/ws`。

动作定义集中在 `src/shared/desktop-actions.ts`，WebSocket frame 和 namespace 定义集中在 `src/shared/desktop-ws.ts`。

## 核心流程

HTTP action bridge：

```text
POST / action call
  -> handleDesktopActionRequest()
  -> validate action definition
  -> read / validate / preview / apply / execute
  -> optional confirmation for mutating page control
  -> response
```

Desktop WebSocket：

```text
client token
  -> verify Desktop access token
  -> session.hello
  -> action.list / action.call / service.* / assistant.startRun
  -> push heartbeat / auth.expiring / service.changed / web.changed
```

Namespace：

- `d`：Desktop。
- `ap`：agent-platform bridge。
- `wa`：webapp。

## 配置与接口

HTTP action bridge 默认：

- host：`127.0.0.1`
- port：`11788`

Desktop WebSocket 默认：

- host：`127.0.0.1`
- LAN bind host：`0.0.0.0`
- port：`7082`
- path：`/ws`

动作类别：

- navigation
- setting
- web
- controlCenter
- market
- help
- kanban
- pet
- page context / CDP interaction

## 约束与注意事项

- WebSocket token 必须通过 identity-center JWK 校验，scope 为 `app`，device id 匹配本机。
- public action aliases 负责兼容简短命名；新能力应补 `DESKTOP_ACTION_DEFINITIONS`。
- 高风险 page interaction 需要确认或 page control grant。
- 旧的 Kanban public issue CRUD 名称不要重新接入；遵守只读云缓存协议。
