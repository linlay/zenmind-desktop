# 配置化与品牌

## 当前状态

Desktop 支持多品牌构建。品牌由 `BRAND` 或 `--brand` 选择，默认品牌是 `zenmind`。品牌配置从 `brands/<brand>/brand.json` 读取，并由 `scripts/sync-brand.mjs` 生成 `build/brands/<brand>/generated/brand.json`、electron-builder 配置、图标、installer include 和运行期品牌资产。

运行时代码通过 `src/shared/brand.ts` 读取注入的 `APP_BRAND`，或在开发环境中回退读取生成的 brand json。

## 核心流程

```text
BRAND / --brand
  -> scripts/lib/brand-config.mjs
  -> brands/<brand>/brand.json + i18n + icons + desktop pet
  -> build/brands/<brand>/generated/brand.json
  -> Electron main / renderer 注入 APP_BRAND
  -> user-paths / packaging / UI 文案 / 图标
```

品牌影响：

- 产品名、appId、packageName、storageNamespace。
- 运行根目录名，例如 `.zenmind`、`.cutej`。
- 平台程序数据目录名，例如 `ZenMind`、`CuteJ`。
- macOS 权限说明、图标、tray icon、桌宠默认资产和 i18n 覆写。主应用 Bundle 固定声明支持简体中文与英语，系统原生面板按 macOS 全局或应用专属语言选择本地化；Desktop 内部语言设置不覆盖系统原生面板语言。麦克风和系统语音识别权限说明默认由 `productName` 生成；只有品牌需要非默认文案时，才在 `mac.microphoneUsageDescription` / `mac.speechRecognitionUsageDescription` 覆写。

## 配置与接口

常用环境变量：

- `BRAND`：选择品牌。
- `DESKTOP_BRAND_JSON`：显式指定运行期 brand json。
- `DESKTOP_BUILTIN_ASSETS_ROOT`：覆盖内置服务资源根目录。
- `DESKTOP_BUILTIN_ASSETS_SOURCE`：覆盖 `sync:assets` 的服务包扫描源。
- `ENV_ZIP`：打包时内置首启环境包。
- `DEMO`：打包时内置本地网站应用 demo。
- `SKIP_NOTARIZE`：macOS 打包跳过公证。
- `DESKTOP_SIGN_DARWIN_BUILTINS` / `SIGN_MAC_BUILTINS`：控制 Darwin 内置服务预签名。
- `DESKTOP_KANBAN_SERVER_URL`、`DESKTOP_KANBAN_TOKEN`、`DESKTOP_KANBAN_REMOTE_CONTROL_ENABLED`、`DESKTOP_KANBAN_PROJECT_ID`：Kanban 远端控制覆盖项。

运行期配置分层：

- Desktop profile：`config/desktop/profile.json`。
- SSO：`config/desktop/sso.json` 和 `state/desktop/sso-session.json`。官网头像缓存只需在品牌
  `desktop-init.json -> sso.avatarCache` 声明 `{ enabled, trustedOrigin }`，不配置第三方头像域名。
- 服务配置：`config/services/<service-id>/.env`。
- 插件配置：`config/plugins/<plugin-id>/.env`。
- 市场配置：`config/desktop/market.json`。
- Kanban 配置：`config/desktop/kanban.json`。
- Desktop Action Bridge：`config/desktop/desktop-action-bridge.json`。
- 企业 IM：`desktop-init.json -> enterpriseIm` 显式声明 `enabled` 与 `baseUrl`，bootstrap 后完整写入 `config/desktop/enterprise-im.json`；该文件是运行期唯一配置源。缺失时默认关闭并回退 `http://127.0.0.1:11956`，远端必须使用 HTTPS。
- Help：`desktop-init.json -> help.url` 在 bootstrap 后写入 `config/desktop/help.json`；远端必须使用 HTTPS，页面必须允许匿名访问。WebView partition 随品牌 `storageNamespace` 隔离。
- 旧 `imServer`、`config/desktop/im-server.json` 和 `profile.general.enterpriseChatEnabled` 已废弃且不迁移。

## 约束与注意事项

- 打包脚本要求发布命令显式提供品牌；普通开发命令可以走默认 `zenmind`。
- 不要把真实 token、证书、私钥或本机 `.env.local` 写入品牌配置或文档。
- 品牌生成物可以重建，修改品牌源文件后应执行 `npm run brand:sync` 或对应打包命令。
- macOS Bundle 使用 `zh-Hans` / `en` 语言标识并以 `zh-Hans` 作为不支持语言的回退；Electron/Chromium 语言包继续使用 `zh-CN` / `en-US`，两套平台标识不得混用。
- 新增品牌必须补齐 brand json、i18n、图标和桌宠必需状态。
- 每个品牌环境包必须显式声明可用的 `help.url`；Desktop 不内置跨品牌默认 Help 地址。
