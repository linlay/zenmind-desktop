# How to create a Chat, Project, or Site

Move the pointer over a group heading in the left sidebar to reveal its actions. If the sidebar is collapsed, expand it first.

## Create a Chat

1. Move the pointer over **Chats**.
2. Select the **New chat** icon on the right.
3. Desktop opens a new conversation with the current default Chat agent.

If the button is unavailable, choose an available default Chat agent in Settings and try again.

## Create a Project

1. Move the pointer over **Projects** and select the `+` button.
2. Choose the project's working directory in the system directory picker.
3. In the Create Project dialog, select **Coder** or **Knowledge Base**. For a Coder project, you can optionally enable ACP and choose a running ACP proxy.
4. Select **Create**. Its new chat opens automatically when the project is ready.

## Create a Site

1. Move the pointer over **Sites** and select the `+` button.
2. Choose **New embedded website**, then enter its name and web address. You can also select a side assistant.
3. Select **Add**. The site is added to Sites and opened immediately.

To add a local website application, select **Import WebApp** from the same `+` menu. The edit icon next to it opens **Manage websites**.
