New installations store desktop runtime data in a layered Desktop data directory:

- **macOS**: `~/.zenmind/.desktop/`
- **Windows**: `%USERPROFILE%\.zenmind\.desktop\`

This directory is organized into `config`, `data`, `state`, `logs`, `cache`, `secrets`, and `profiles`. Service and plugin program files live in the ZenMind directory under the system Application Support location.
