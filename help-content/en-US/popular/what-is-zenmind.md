ZenMind is a desktop control shell for managing and running built-in services and third-party plugins in one place. It is built on Electron and provides service discovery, installation, start/stop controls, log viewing, and configuration management.

ZenMind supports two service sources: [**built-in services**](/control-center), which ship with the app, and [**plugins**](/market), which can be imported at runtime from `{{pluginArchiveLabel}}` packages.
