# 如何新建 Chat、Project 和 Site

在左侧边栏将鼠标移到对应分组标题上，即可看到右侧的操作按钮。侧边栏收起时，先展开它再进行操作。

## 新建 Chat

1. 将鼠标移到 **Chats** 标题。
2. 点击右侧的“新建对话”图标。
3. Desktop 会用当前默认 Chat 智能体打开一个新对话。

如果按钮不可用，请到设置中选择可用的默认 Chat 智能体后重试。

## 新建 Project

1. 将鼠标移到 **Projects** 标题，点击右侧的 `+`。
2. 在系统目录选择器中选取项目工作目录。
3. 在“创建项目”窗口中选择 **代码助手** 或 **知识库**；代码助手可按需启用 ACP 并选择正在运行的 ACP 代理。
4. 点击“创建”。创建完成后会自动打开该项目的新对话。

## 新建 Site

1. 将鼠标移到 **Sites** 标题，点击右侧的 `+`。
2. 选择“新增内嵌网站”，填写网站名称和网页地址；也可以选择一个侧边智能助手。
3. 点击“添加”，新网站会立即出现在 Sites 中并打开。

如需导入本地网站应用，请在同一个 `+` 菜单中选择“导入 WebApp”。旁边的编辑图标用于进入“管理网站”。
